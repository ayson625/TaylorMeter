# TaylorMeter
Program for auto-measuring bubble and slug for Taylor flow in microchannels

[![Скачать приложение](https://img.shields.io/badge/↓_Download-2563EB?style=for-the-badge)](https://github.com/ayson625/TaylorMeter/releases/latest/download/TaylorMeter_3.0.zip)

1.Unzip the archive

2.Click on start_windows

3.Saved data located in /saves folder

*How to use*

1.Set the values for flow rate of two phases that will be appeared as the headings of columns in Excel

2.Draw rectangle capturing microchannel

3.Scale is set automatically by default and quite precise, you can set manually if you want

4.Drag the boundaries of bubble or slug if needed

5.Add or delete bubbles if needed

6.Check if everything is right measured and click on review button

- If you dont change the flow rates while editing new photos, columns with measured values will be kept under the same heading in excel

7.Save the Excel spreadsheet, it will contain the measured data of all opened photos

8.Saved data located in /saves folder inside TaylorMeter folder
